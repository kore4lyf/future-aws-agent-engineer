# Transformers for Sequential Modeling

Self-attention mechanisms allow neural networks to weigh token relationships independently of distance. Encoder-decoder transformers dominate machine translation, while decoder-only variants power modern language models. Positional encodings preserve order information that attention alone would discard.

Practical training uses scaled dot-product attention with multi-head projections. Layer normalization and residual connections stabilize deep stacks. Cross-domain applications include code generation, time-series forecasting, and retrieval-augmented generation pipelines.
