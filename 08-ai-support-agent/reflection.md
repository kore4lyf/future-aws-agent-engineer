# Reflection - AI Support Agent

One decision I made early was to keep both order and refund tools behind the AgentCore Gateway instead of calling the Lambdas directly. It would have been simpler to import the handler functions, but using MCPClient with streamable_http_client meant the agent saw order-tracker get_order and refund-processor initiate_refund as normal tools. No custom auth handling and no proxy parsing in the agent code. The downside was more setup with the REST API stage and operation names, but it feels closer to how a real support system would expose services.

The biggest challenge was permissions. The Gateway worked right away, but the first Knowledge Base call failed and then Memory failed too. The runtime role did not have retrieve access to the KB or get and create access to Memory. I had to add two small inline policies to the runtime role, one for bedrock Retrieve on the KB and one for Memory on CustomerSupportMemory, and retry without redeploying. The browser did the same thing later. StartBrowserSession was denied even though the actions were allowed, because the resource was browser slash star. Changing it to star fixed it, and then the automation stream needed a wildcard for Browser as well. Each time I had to read the exact denied action from the response instead of guessing.

For production, the main thing I noticed is how easy it is to leave costly resources running. Deleting the Knowledge Base does not delete the OpenSearch Serverless collection or the S3 bucket with the catalog. If you forget them, the fifteen dollar estimate keeps running. The NONE authorizer and the wildcard browser resource were fine for the lab, but in production I would switch to an OAuth authorizer and least privilege ARNs. The other lesson was the deployment size. With OpenTelemetry the zip was 111 MB and cold starts hit the thirty second limit, and lab IAM blocked StartDiscovery so the GenAI dashboard stayed empty. That showed me observability has to be enabled by the platform team and keeping the bundle small is a reliability issue, not just a build tweak.
